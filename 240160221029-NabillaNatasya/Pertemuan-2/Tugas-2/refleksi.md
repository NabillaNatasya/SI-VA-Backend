## 1. Tiga Fitur JavaScript Modern yang Mengubah Cara Menulis Kode

### a. Arrow Function

Arrow function membuat penulisan fungsi menjadi lebih singkat dan sederhana.

Saya menggunakannya pada proses refactor sehingga fungsi yang sebelumnya menggunakan `function` dapat ditulis dengan bentuk yang lebih ringkas.

### b. Destructuring

Destructuring memudahkan saya mengambil data tertentu dari object tanpa harus menuliskan akses property secara berulang. Contohnya, saya dapat mengambil property `judul` langsung dari object buku.

### c. Promise dan Async/Await

Promise dan async/await membantu saya memahami bagaimana proses asynchronous bekerja pada backend. Saya menggunakannya pada service buku untuk menjalankan operasi seperti mengambil, menambah, mengubah, dan menghapus data dengan delay seolah-olah sedang mengambil data dari database.

## 2. Hal yang Masih Membingungkan

Hal yang masih cukup membingungkan bagi saya adalah cara kerja asynchronous dan Promise, terutama ketika beberapa proses dijalankan secara bersamaan menggunakan `Promise.all()`. Saya masih perlu memahami lebih dalam mengenai urutan proses asynchronous dan bagaimana JavaScript menjalankan beberapa proses tersebut secara bersamaan.
